## USB·LiDAR·MCU

`ttyUSB` 번호는 재부팅과 연결 순서에 따라 바뀔 수 있습니다. 특정 시점의 `CP2102N=/dev/ttyUSB0`, `CH340=/dev/ttyUSB1` 기록을 고정 설정으로 사용하지 말고 장치 속성과 `by-id`를 확인합니다.

```bash
ls -l /dev/serial/by-id/
readlink -f /dev/myserial
udevadm info -q property -n /dev/ttyUSB0 | grep -E "ID_VENDOR=|ID_MODEL=|ID_SERIAL="
ros2 topic hz /scan
ros2 topic echo /scan --once
```

`SL_RESULT_OPERATION_TIMEOUT`은 포트 불일치, 점유, 권한, 전원·케이블 또는 baudrate를 순서대로 진단합니다. `/scan`이 지속 발행되고 RViz 형상이 실제 장애물과 함께 갱신되는지까지 확인해야 합니다.

## 카메라와 보정

V4L2 장치 번호와 실제 영상 캡처 노드를 먼저 확인합니다. 보정 YAML의 해상도와 실제 Image 해상도가 같아야 하며, ArUco에는 같은 파이프라인의 `/image_rect`와 `/camera_info_rect`를 사용합니다.

```bash
v4l2-ctl --list-devices
v4l2-ctl --device=/dev/video0 --list-formats-ext
ros2 topic hz /camera/image_raw
ros2 topic hz /image_rect
ros2 topic echo /camera_info_rect --once
```

## 차선·횡단보도·벽 감지

현장 원인이 영상·LiDAR 로그 없이 확정되지 않은 부분 확인 사례입니다.

- 차선: 카메라 자세와 보정, BEV, 색 임계값, lookahead·gain·속도를 단계별로 분리합니다.
- 횡단보도: `cross raw`, `confirmed`, `score`와 검출 박스를 기록해 단일 프레임 오탐을 확인합니다.
- 벽 감지: 원본 `/scan`의 전방 각도와 유효 거리 분포를 확인하고, 최솟값 하나만으로 정지하지 않는지 점검합니다.
- Deep Learning Lane: 기록된 validation accuracy 약 86.7%를 실차 주행 성공률로 해석하지 않습니다.

## ArUco와 Active Vision

기록된 기준은 `DICT_4X4_50`, 목표 ID 40, marker size 0.120m입니다. 실제 마커와 다른 경우 현장 값이 우선입니다.

```bash
ros2 topic hz /image_rect
ros2 topic echo /aruco/ids --once
ros2 topic info /aruco/centers -v
ros2 topic echo /camera/pan_cmd --once
ros2 run r2_description camera_tf_node
ros2 run r2_active_vision camera_sweep_node
```

tracker와 sweep 노드를 동시에 실행해 서보 명령이 경쟁하지 않도록 합니다. Pan/Tilt 원점과 안전 가동 범위는 설치된 코드와 실기구에서 다시 확인합니다.

## SLAM, TF와 Nav2

진단 순서는 센서 → TF → SLAM/localization → Nav2 lifecycle입니다.

```bash
ros2 topic hz /scan
ros2 topic hz /odom
ros2 run tf2_ros tf2_echo odom base_link
ros2 run tf2_ros tf2_echo base_link laser
ros2 run tf2_tools view_frames
ros2 lifecycle nodes
```

- `map → odom → base_link → laser` 체인과 시간 갱신을 확인합니다.
- Nav2 YAML이 `/scan_filtered`를 사용하면 해당 필터 토픽의 실제 발행자를 확인합니다.
- Jazzy 기록에서 local costmap `width: 3.0`, `height: 3.0`이 타입 오류를 낸 사례는 정수 `3`으로 해결됐지만, 사용 중인 로그와 파라미터 타입을 먼저 대조해야 합니다.
- R2는 Ackermann 구조이므로 제자리 회전 명령을 물리적으로 수행할 수 없습니다. planner/controller 설정 제안은 완전한 자율주행 성공을 뜻하지 않습니다.

## 사람 추종·모터·엔코더

사람 추종 노드는 기본 DISARMED 상태, 센서 stale 정지와 `/cmd_vel_raw → obstacle_stop → /cmd_vel` 안전 흐름을 확인합니다. Rosmaster 통신 성공과 엔코더 채널·부호·단위 보정은 별개의 검증 항목입니다.

PWM 핀·클록 기록은 모든 Jetson 캐리어 보드에 공통이 아닙니다. 디바이스 트리나 권한을 변경하기 전에 실제 핀맵과 오실로스코프 파형을 확인하세요.
