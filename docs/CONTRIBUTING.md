# 지식베이스 기여 가이드

[README로 돌아가기](../README.md) · [아키텍처](ARCHITECTURE.md) · [공통 진단](TROUBLESHOOTING.md)

이 프로젝트는 확인된 경험과 출처를 우선합니다. 일반적인 해결 가설을 실제 해결 사례처럼 기록하지 마세요.

## 기여 범위

- 새로운 A1 또는 R2 오류 사례
- 기존 항목의 재현 결과·출처·검증 상태 보강
- 한국어 표현과 동의어 검색 개선
- 접근성·반응형 UI와 문서 개선
- 근거가 있는 안전 주의사항

라이선스, AI API, 서버 기능, 원격 장비 제어는 별도 논의 없이 추가하지 않습니다.

## 먼저 확인할 사항

1. 대상이 A1인지 R2인지 확정합니다.
2. OS, ROS 2 배포판, 작업공간, 센서와 드라이버를 기록합니다.
3. 기존 `id`, 제목, 증상, 오류 키워드와 중복되는지 검색합니다.
4. 문제의 최종 해결·검증 여부를 구분합니다.
5. 비밀번호, 토큰, SSH 키, 개인 경로와 민감 로그를 제거합니다.

## 항목 스키마

`data/knowledge-base.json`의 `entries`에 다음 형태로 추가합니다.

```json
{
  "id": "a1-or-r2-unique-id",
  "model": "A1",
  "environment": ["Ubuntu 버전", "ROS 2 배포판", "확인된 센서"],
  "title": "문제를 구분할 수 있는 제목",
  "symptoms": ["실제로 관찰한 증상 또는 오류 원문"],
  "keywords": ["한국어 표현", "error_code", "topic_name"],
  "causes": ["확정 원인 또는 가능한 원인임을 명시한 설명"],
  "diagnostics": [
    {"os": "A1 Ubuntu / ROS 2 Humble", "cmd": "검증된 읽기 전용 확인 명령"}
  ],
  "solutions": ["결과에 따른 해결 방법 또는 다음 진단 단계"],
  "verification": ["정상 동작을 판단하는 방법"],
  "sources": [
    {"label": "출처 이름", "url": "https://example.com/source"}
  ],
  "status": "partially-verified",
  "statusLabel": "부분 확인 · 전체 해결 미확정"
}
```

예시 값은 필드 형식을 보여줄 뿐 실제 명령이나 출처로 사용하면 안 됩니다.

## 상태 선택

| 상태 | 사용 조건 |
|---|---|
| `verified` | 특정 환경에서 출력·동작 또는 해결 결과가 실제로 확인됨 |
| `partially-verified` | 진단 절차나 일부 동작만 확인됐고 전체 해결은 미확정 |
| `unverified` | 문제는 관찰했으나 최종 원인·해결 검증이 없음 |

`verified`도 모든 장비와 환경에서의 재현을 뜻하지 않습니다. `statusLabel`에는 범위를 사람이 읽을 수 있게 적습니다.

## 작성 원칙

- A1 Humble과 R2 Jazzy 설정을 한 항목에 혼합하지 않습니다.
- `ttyUSB`, `/dev/videoX`, ROS_DOMAIN_ID를 모든 장비의 고정값으로 서술하지 않습니다.
- 오류 원문은 검색할 수 있도록 `symptoms`와 `keywords`에 보존합니다.
- 여러 원인이 가능하면 안전한 진단 순서로 작성합니다.
- `diagnostics`에는 실제로 확인된 명령만 넣고 대상 OS를 표시합니다.
- 파괴적 명령, 강제 권한 완화, 안전 계층 우회는 권장하지 않습니다.
- URL이 없는 경험 기록은 `url: null`로 저장할 수 있습니다.
- 같은 사례가 있으면 새 항목보다 기존 항목 보강을 우선합니다.

## 로컬 검증

JSON 문법과 정적 파일을 확인합니다. Node.js가 있는 개발 환경에서는 원본 개발 저장소의 테스트를 함께 실행해야 합니다.

```powershell
Get-Content data\knowledge-base.json -Raw | ConvertFrom-Json | Out-Null
```

검토 항목:

- A1/R2 항목 수와 모델 분리
- 오류 코드·한국어 질문 검색
- 근거 없는 답변 차단
- 명령어 복사와 출처 표시
- 모바일 레이아웃
- 상대 자산 경로
- 비밀정보와 개인 경로 부재
